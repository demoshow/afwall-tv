# Upstream links, donations and unlockers

This TV port is free software under GPL-3.0 and does not sell anything. It is
not an official AFWall+ release.

- Upstream project: https://github.com/ukanth/afwall
- Upstream support/donations:
  https://github.com/ukanth/afwall#support-afwall-development
  (supports upstream, not this TV port)
- The upstream donor application ID `dev.ukanth.ufirewall.donate` and the
  upstream unlocker key are external AFWall+ products. This TV build sets
  `DONATE=false`; it does not sell or promise an unlocker.
- TV bug reports and feature requests:
  https://github.com/demoshow/afwall-tv/issues
- The inherited `playstore/` artwork is historical upstream store art, not a
  listing for this TV port.

  `LICENSE`, `NOTICE.md` and `THIRD_PARTY.md`.
